Put it all together: a todo app

Your app

    0 left

    Goal

    Build a working todo list. It uses almost everything so far: variables, functions, conditions, loops, arrays of objects, array methods, the DOM, and events.

    You'll use

    • an array of objects as state
    • render()
    • .filter()
    • .find()
    • event delegation
    • .trim()

    The plan

    All the data lives in one array. Every action changes the array, then calls render(), which rebuilds the list from scratch. It's the counter from 4.2, with a list in place of a number.

    let todos = [
  { id: 1, text: "Buy milk", done: false },
  { id: 2, text: "Learn JS", done: true },
];

    Steps

    1. render(): empty #list, then make an <li> for each todo (the starter builds most of it for you).
    2. Give the <li> the class done when the todo is done, and tick its checkbox.
    3. Show how many are not done in #remaining, as "2 left".
    4. Adding: on submit, trim the text. If it's empty, do nothing. Otherwise push a new todo, clear the input and render.
    5. Toggling and deleting: one click listener on #list works out which todo was clicked and what was clicked on.
    6. Clear completed keeps only the todos that aren't done.

    Event delegation. The <li>s get destroyed and rebuilt on every render, so listeners attached to them would disappear too. Put one listener on #list, which never changes. event.target tells you what was actually clicked.

    Think about it

    • Why does every todo need an id? Why not find it by its text?
    • Rebuilding the whole list on every change sounds slow. When would it start to matter? (This is part of why frameworks like React exist.)
    Bonus
    • Save the todos so they survive a refresh: localStorage.setItem("todos", JSON.stringify(todos)) at the end of render(), and JSON.parse(localStorage.getItem("todos")) at the start.
    • Show "1 item left" for one and "2 items left" for more.
    • Double-click a todo to edit its text.
