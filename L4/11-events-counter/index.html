Level 4 · The page · Task 2

Events: a click counter

Your page: click the buttons

0

Goal

Make the page react to the user. The buttons do nothing yet. You'll use events to run code when they're clicked.

You'll use

  • addEventListener("click", fn)
  • state (let count)
  • a render() function
  • .disabled
  • classList.toggle()
button.addEventListener("click", () => {
  // this runs every time the button is clicked
});

Steps

  1. Write render(): it puts the value of count into #count.
  2. + adds 1 to count, then calls render().
  3. − subtracts 1, but never goes below 0.
  4. Reset sets count back to 0.
  5. In render(): disable the − button when the count is 0.
  6. In render(): when the count is 10 or more, show "That's a lot of clicks!" in #message and add the class high to #count. Below 10, clear both.

The big idea: state → render. Keep the truth in a variable (count). Every event changes the variable and then calls render(), which makes the page match it. Don't read the number back out of the page. React, Vue and most other frameworks are built on this idea.

Think about it

  • Why write render() once instead of updating the text inside each click handler?
  • Why pass the function itself (render) instead of calling it (render()) when you hand it to addEventListener?
Bonus

Keyboard support: listen for "keydown" on document. ↑ adds, ↓ subtracts. Check event.key === "ArrowUp".
