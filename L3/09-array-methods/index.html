Level 3 · Data · Task 3

Array methods: map, filter, reduce

Goal

Answer questions about a shop's products, usually in one line each. These methods are how real frontend code handles lists: search results, shopping carts, feeds.

You'll use

  • .forEach()
  • .map()
  • .filter()
  • .find()
  • .reduce()
  • chaining
[1, 2, 3].map(n => n * 10)        // [10, 20, 30]  change every item
[1, 2, 3].filter(n => n > 1)      // [2, 3]        keep some items
[1, 2, 3].find(n => n > 1)        // 2             the first match
[1, 2, 3].reduce((sum, n) => sum + n, 0)   // 6   boil down to one value

Steps

  1. Use forEach to log each product as "Notebook: $4".
  2. names: an array of just the product names.
  3. available: only the products that are in stock.
  4. cheapNames: names of products under $10. Chain filter then map.
  5. backpack: the product object whose name is "Backpack".
  6. total: the sum of all prices, with reduce.
  7. stockValue: the sum of prices of in-stock products only.

Which one do I need? Same number of items, but changed → map. Fewer items → filter. One item → find. One value (a total, a count) → reduce. Just doing something, like logging → forEach.

Think about it

  • Do map and filter change the original products array? Log it at the end and see.
  • What does find return when nothing matches?
  • Could you write total with a for...of loop instead? (Yes. reduce is the same accumulator pattern from task 2.3.)
Bonus

sortedNames: product names from cheapest to most expensive. .sort() changes the array it's called on, so copy it first with [...products].
