Level 3 · Data · Task 1

Arrays: lists of things

Goal

Keep many values in one variable, read them by position, add to the list, and loop over it to answer questions like "what's the biggest?"

You'll use

  • [a, b, c]
  • list[0]
  • .length
  • .push()
  • for...of
const colors = ["red", "green", "blue"];
//  position:     0        1       2
colors[0];        // "red"
colors.length;    // 3
colors.push("pink");  // now 4 items

Steps

  1. firstFruit: the first item of fruits.
  2. lastFruit: the last item. Use .length, so it works for a list of any size.
  3. Add "mango" to the end of fruits.
  4. largest(numbers): loop through and return the biggest number. No Math.max!
  5. contains(list, item): loop and return true or false.
  6. reverseCopy(list): return a new array in reverse order, leaving the original as it was. No .reverse()!

Counting starts at 0. The first item is [0], so the last item is [length - 1]. Getting this wrong is so common it has a name: the off-by-one error.

Think about it

  • What does fruits[10] give you? Does it crash?
  • fruits is a const, yet push still changes it. How? (The box always holds the same list. The list's contents can change.)
  • In largest, what goes wrong with all-negative numbers if you start with let biggest = 0?
Bonus

Now use the built-in shortcuts: list.includes(item) and Math.max(...numbers). Writing a loop yourself first is how you learn what these do inside.
