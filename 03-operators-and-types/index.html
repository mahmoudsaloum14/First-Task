Level 1 · Basics · Task 3

Operators & type surprises

Goal

Work out a shopping bill, then meet JavaScript's most famous surprise: "5" + 3 is not 8.

You'll use

  • + - * /
  • % remainder
  • > < >=
  • true / false
  • Number()
  • === vs ==

Steps

The file starts with price = 25 and quantity = 3.

  1. total: price times quantity.
  2. withTax: the total plus 15% tax. (15% of x is x * 0.15.)
  3. isExpensive: is withTax more than 80? This is a boolean, true or false.
  4. leftover: 17 sweets shared between 5 kids. How many are left over? Use %.
  5. wrongSum: fromInput + 3. Log it and look closely.
  6. rightSum: turn fromInput into a number first with Number(), then add 3.
  7. looseEqual = fromInput == 5 and strictEqual = fromInput === 5. Log both.

Why this matters: anything a user types into a form reaches JavaScript as a string, even in a number field. You'll hit this in Level 4.

Think about it

  • When one side of + is a string, JS joins text instead of adding. Does "5" * 3 do the same? Try it.
  • == converts types before comparing. === doesn't. Which one should you use? (Almost always ===.)
  • What does Number("hello") give you?
Bonus

Log 0.1 + 0.2. It isn't 0.3. Computers store decimals in binary, so some can't be stored exactly. That's why prices are often counted in cents.
