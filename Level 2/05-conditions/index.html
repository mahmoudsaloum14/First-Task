Level 2 · Logic · Task 2

Conditions: making decisions

Goal

Make your code choose what to do. Each function below takes an input and uses if / else to pick the right answer.

You'll use

  • if
  • else if
  • else
  • && and
  • || or
  • >=
if (temperature > 30) {
  return "hot";
} else if (temperature > 15) {
  return "nice";
} else {
  return "cold";
}

Steps

  1. canVote(age) returns true for 18 and over, otherwise false.
  2. letterGrade(score): 90+ → "A", 80+ → "B", 70+ → "C", 60+ → "D", anything lower → "F".
  3. ticketPrice(age): under 5 → 0, under 18 → 5, 65 and over → 7, everyone else → 10.
  4. canEnter(age, hasTicket): true only when the person is 12 or older and has a ticket.

Order matters. JavaScript checks conditions top to bottom and stops at the first one that's true. If you check score >= 60 first, a score of 95 gets a "D".

Think about it

  • Is 90 an A or a B? Do you need > or >=? The checks test the edges on purpose.
  • Since age >= 18 is already true or false, can you write canVote without an if?
Bonus

Make letterGrade return "Invalid" for scores below 0 or above 100. You'll need ||.
