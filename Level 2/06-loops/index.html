Level 2 · Logic · Task 3

Loops: doing things again and again

Goal

Let the computer handle the repetition. You'll add up numbers, build a countdown, play FizzBuzz and count letters.

You'll use

  • for (let i = 1; i <= n; i++)
  • for (const x of text)
  • while
  • +=
for (let i = 1; i <= 3; i++) {
  console.log(i);   // 1, then 2, then 3
}
// start here ↑   keep going while ↑   after each round ↑

Steps

  1. sumTo(n) adds 1 + 2 + … + n. sumTo(3) → 6.
  2. countdown(n) returns the text "3 2 1 Liftoff!" for n = 3.
  3. fizzBuzz(n) returns "FizzBuzz" if n divides by 3 and 5, "Fizz" if by 3, "Buzz" if by 5, otherwise the number as text. Then log 1 to 15 with a loop.
  4. countVowels(word) counts a, e, i, o, u, capitals included.
  5. doublingsUntil(limit): start at 1 and keep doubling. How many doublings until you reach the limit or pass it? Use while.

The accumulator pattern. Make a variable before the loop (let total = 0), change it inside the loop (total += i), and return it after. Most loops you'll ever write look like this.

Think about it

  • What happens if a while condition never becomes false? (Don't try this with unsaved work open. The tab will freeze.)
  • When would you use for...of instead of a counting for loop?
Bonus

Write multiplicationTable(n) that logs "3 x 1 = 3" up to "3 x 10 = 30".
