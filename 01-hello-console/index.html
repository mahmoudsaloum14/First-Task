Level 1 · Basics · Task 1

Hello, Console

Goal

Make JavaScript print things. console.log() is how you look inside your program. You'll use it in every task from now on.

You'll use

  • console.log()
  • "strings"
  • numbers
  • // comments
  • typeof

Steps

Open starter.js in your editor. Each step is a TODO in the file.

  1. Log the exact text "Hello, JavaScript!"
  2. Log your own name (a string).
  3. Log the number 7, with no quotes.
  4. Log how many hours are in a week. Let JavaScript do the maths: 7 * 24.
  5. Log typeof "hello" and then typeof 42.
  6. Log two or more values in one call: console.log("Age:", 20).

Real developers use DevTools. Press F12 (or Cmd+Option+J on Mac) and open the Console tab. You'll see the same output there.

Think about it

  • What's the difference between console.log(7) and console.log("7")? Look at the colours in the console.
  • Delete a closing ) and refresh. Read the error message. What line does it point to?
Bonus
  • Try console.warn("careful") and console.error("oops").
  • What does typeof true give? And typeof undefined?
